# Auditorias e Inventários

Esta pasta reúne evidências históricas e inventários somente leitura do projeto.

- `supabase_*`: baselines, auditorias e inventários dos ambientes Supabase.
- `csp_*`: inventário relacionado à política de segurança de conteúdo.
- `innerhtml_*`: inventário de renderizações HTML e controles contra XSS.

Os arquivos desta pasta documentam estados já observados. Eles não devem ser
tratados como migrations nem como fonte de credenciais ou dados de negócio.
